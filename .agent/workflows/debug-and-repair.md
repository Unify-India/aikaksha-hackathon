# Workflow: Debug and Repair

1. Reproduce failure.
2. Capture logs without secrets or student PII.
3. Classify failure.
4. Inspect relevant code and dependency versions.
5. Add regression test.
6. Apply bounded fix.
7. Re-run focused tests and full relevant checks.
8. Verify security was not weakened.
9. Report root cause, fix, tests and remaining risk.
