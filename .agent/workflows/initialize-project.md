# Workflow: Initialize Project

1. Read root instructions and rules.
2. Check OS, Git, Node, package manager, Google Cloud CLI and repository state.
3. Run `scripts/doctor.sh`.
4. Inspect both repositories; do not edit Abhyas.
5. Complete repository inspection report.
6. Verify Gemini mobile MCP feasibility with a tiny read-only prototype before building business tools.
7. Propose architecture decisions and obtain review.
8. Create implementation branches/worktrees and assign file ownership.
9. Enable feature flags only as end-to-end flows pass.
10. Report blockers and readiness.
