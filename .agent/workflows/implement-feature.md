# Workflow: Implement Feature

1. State goal, acceptance criteria, files likely affected and assumptions.
2. Read relevant skill and architecture decisions.
3. Inspect existing implementation and tests.
4. Confirm no unresolved human-review decision blocks work.
5. Implement smallest end-to-end slice.
6. Add schema validation, authorization and failure handling.
7. Add unit/integration/negative tests.
8. Run focused tests, typecheck, lint and build.
9. Update docs and environment template.
10. Report exact files, tests, limitations and next dependency.
