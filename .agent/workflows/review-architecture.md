# Workflow: Architecture Review

Produce:
- Context and scope.
- Current state evidence.
- Proposed component and trust-boundary diagram.
- Data flow and data classification.
- Authentication and authorization model.
- API/MCP contract changes.
- Failure modes, idempotency and observability.
- Cost/quota considerations.
- Alternatives and trade-offs.
- Migration/rollback.
- Tests and acceptance criteria.
- Explicit decisions requiring owner approval.

Do not implement while the review is pending.
