# Eight-Hour Delivery Rule

Optimize for two complete, reliable demonstrations, not feature count.

Priority:
P0: environment, source discovery, auth boundary, Gemini mobile feasibility gate.
P1: exam draft generation and assignment in a test tenant.
P2: one handwritten answer sheet evaluated and annotated.
P3: deployment, negative tests, rehearsed demo, fallback recording.

If time slips:
- Preserve the exam end-to-end path.
- Reduce subjective evaluation to one known sample answer sheet and one rubric.
- Use deterministic overlay annotations rather than image generation.
- Do not remove authorization, teacher confirmation, original-file preservation, or tests.
